# Glossary

## ADJSCC

Attention-based Deep Joint Source-Channel Coding.

## DeepJSCC

Deep Joint Source-Channel Coding. It uses neural networks to learn source coding and channel coding jointly.

## CIFAR-10

A small image classification dataset with 32x32 RGB images. It is suitable for the first reproduction stage.

## SNR

Signal-to-noise ratio. In image transmission experiments, different SNR values simulate different channel conditions.

## AWGN

Additive White Gaussian Noise channel.

## PSNR

Peak Signal-to-Noise Ratio, a common image reconstruction quality metric.

## SSIM / MS-SSIM

Structural Similarity / Multi-Scale Structural Similarity, perceptual image quality metrics.
