# Results

This folder is for small, curated result summaries and figures that are useful for reports.

Large files should stay outside the Git repository:

```text
D:/Research/ai-data/runs/ADJSCC
D:/Research/ai-data/checkpoints/ADJSCC
```

Recommended tracked content:

- Small `.png` or `.jpg` figures for reports.
- Small `.csv` summaries.
- Markdown notes explaining experiment settings.

Do not commit large checkpoints, raw logs, full datasets, or long tensor dumps.
